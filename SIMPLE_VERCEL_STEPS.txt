   🚀 VERCEL DEPLOYMENT - SIMPLE STEPS
═══════════════════════════════════════════════════════════

✅ YOUR CODE IS ALREADY ON GITHUB!

Vercel should be auto-deploying right now. Here's what to do:

═══════════════════════════════════════════════════════════

STEP 1: CHECK VERCEL DEPLOYMENT (2 MINUTES)
───────────────────────────────────────────────────────────

1. Go to: https://vercel.com/dashboard
2. Find your Tesla project
3. You should see a new deployment in progress
4. Wait for it to finish (shows "Ready")

═══════════════════════════════════════════════════════════

STEP 2: GET PRODUCTION DATABASE URL (1 MINUTE)
───────────────────────────────────────────────────────────

1. In Vercel Dashboard → Your Project
2. Click "Settings" tab
3. Click "Environment Variables"
4. Find "POSTGRES_PRISMA_URL" 
5. Click "Show" and copy the FULL URL
   (looks like: postgresql://username:password@host/database)

═══════════════════════════════════════════════════════════

STEP 3: UPDATE PRODUCTION DATABASE (2 MINUTES)
───────────────────────────────────────────────────────────

OPTION A - Using Local Command (Easiest):
──────────────────────────────────────────

1. Create file: c:\Projects\Tesla\.env.production.local

2. Add these lines (replace with your URL from Step 2):
   POSTGRES_PRISMA_URL="your-url-here"
   POSTGRES_URL_NON_POOLING="your-url-here"

3. Open Command Prompt in c:\Projects\Tesla

4. Run: npx prisma db push

5. Delete the .env.production.local file (security!)


OPTION B - Using Database Client:
──────────────────────────────────

1. Connect to your production database using pgAdmin, 
   DBeaver, or Vercel's Postgres dashboard

2. Run this SQL:
   ALTER TABLE "User" 
   ADD COLUMN "isSuperAdmin" BOOLEAN NOT NULL DEFAULT false;

═══════════════════════════════════════════════════════════

STEP 4: CREATE SUPER ADMIN (2 MINUTES)
───────────────────────────────────────────────────────────

OPTION A - Update Existing Admin (Easiest):
───────────────────────────────────────────

If you already have admin@teslacapx.com in production:

1. Connect to your production database
2. Run this SQL:
   UPDATE "User" 
   SET "isSuperAdmin" = true, "role" = 'ADMIN'
   WHERE "email" = 'admin@teslacapx.com';


OPTION B - Create New Admin:
────────────────────────────

If admin@teslacapx.com doesn't exist in production:

1. Open Command Prompt
2. Run these commands:

   npm install -g vercel
   vercel login
   cd c:\Projects\Tesla
   vercel link
   vercel env pull
   vercel exec npm run seed:admin

═══════════════════════════════════════════════════════════

STEP 5: TEST ON PRODUCTION (1 MINUTE)
───────────────────────────────────────────────────────────

1. Go to your live website (your-domain.vercel.app)
2. Login with:
   Email: admin@teslacapx.com
   Password: Admin@12345
3. Go to: /admin/users
4. Verify you don't see yourself in the list ✅
5. Find your friend's account
6. Delete or demote them ✅

═══════════════════════════════════════════════════════════

⚡ FASTEST WAY (IF YOU HAVE DATABASE ACCESS):
───────────────────────────────────────────────────────────

Just run these 2 SQL commands on production database:

1. Add the field:
   ALTER TABLE "User" 
   ADD COLUMN "isSuperAdmin" BOOLEAN NOT NULL DEFAULT false;

2. Update your admin:
   UPDATE "User" 
   SET "isSuperAdmin" = true, "role" = 'ADMIN'
   WHERE "email" = 'admin@teslacapx.com';

DONE! Test on your live site.
