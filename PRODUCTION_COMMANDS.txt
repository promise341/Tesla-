🗄️ STEP 3: UPDATE PRODUCTION DATABASE

You need to add the "isSuperAdmin" field to your production
database. Here are the options:

OPTION A - Run migration locally (safest):
   ────────────────────────────────────────────────────────
   1. Get your production database URL
   2. Temporarily update .env:
      POSTGRES_PRISMA_URL="your-production-url"
   
   3. Run: npx prisma db push
   
   4. Restore .env to local settings
   ────────────────────────────────────────────────────────

OPTION B - SQL command (if you have database access):
   ────────────────────────────────────────────────────────
   Run this in your PostgreSQL client:
   
   ALTER TABLE "User" 
   ADD COLUMN "isSuperAdmin" BOOLEAN NOT NULL DEFAULT false;
   ────────────────────────────────────────────────────────
